# 生产计划工作台

一个可直接部署到 GitHub Pages 的静态排产应用。包含总览、甘特图、任务列表与看板、物料缺口测算、生产批次和风险跟踪。

## 使用

通过 HTTPS 网站地址输入交付的随机账号和密码。计划数据使用 PBKDF2 SHA-256（310000次）派生 AES-256-GCM 密钥后解密；密码和明文计划不保存在仓库中。密码遗失后无法解密。

修改加密保存至当前浏览器 localStorage。支持导出和导入加密 JSON 备份；不同浏览器不会自动同步，多人同时编辑时需协调版本。网站不提供服务端用户管理或云端共享数据库。

GitHub Pages 发布 main 分支根目录；`.nojekyll` 禁用不必要的生成。纯 HTML、CSS、JavaScript，无第三方运行时或外部资源。

本地预览需使用 HTTP localhost 服务，不要通过 file URL 直接打开。生产部署使用 HTTPS。不要把登录信息、解密计划、业务原件或本机备份提交到仓库。
